# Sistema Bancario - Git Flow

## Descripción

Este proyecto fue desarrollado como práctica académica del programa Tecnólogo en Análisis y Desarrollo de Software (ADSO) del SENA.

El objetivo fue aplicar la metodología Git Flow para controlar el desarrollo de un sistema bancario utilizando Git y GitHub.

---

## Funcionalidades

El sistema cuenta con los siguientes módulos:

- Gestión de clientes.
- Gestión de cuentas.
- Transferencias bancarias.
- Reportes.
- Control de versiones mediante Git Flow.

---

## Flujo de trabajo utilizado

Durante el desarrollo se implementó la metodología Git Flow utilizando las siguientes ramas:

- main
- develop
- feature/clientes
- feature/cuentas
- feature/transferencias
- feature/reportes
- release/1.0.0
- hotfix/1.0.1
